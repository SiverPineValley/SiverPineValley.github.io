## 1. 문제 소개

> N장의 카드가 있다. 각각의 카드는 차례로 1에서 N까지 번호가 붙어 있으며, 1번 카드가 가장 위, N번 카드가 가장 아래인 상태로 놓여 있다. 이제 다음과 같은 동작을 카드가 1장 남을 때 까지 반복한다.
> 
> 먼저 가장 위에 있는 카드를 바닥에 버린다. 그 다음 가장 위에 있는 카드를 가장 아래에 있는 카드 밑으로 옮긴다. 예를 들어 N=4일 때를 생각해 보자. 카드는 가장 위에서부터 1,2,3,4의 순서대로 놓여 있다. 1을 버리면 2,3,4가 남는다. 여기서 2를 가장 아래로 옮기면 순서가 3,4,2가 된다. 3을 버리면 4,2가 남고, 4를 밑으로 옮기면 순서가 2,4가 된다. 마지막으로 2를 버리면 카드 4가 남는다. N이 주여졌을 때 가장 마지막에 남는 카드를 구하는 프로그램을 작성하시오.
>
> 입력: 1번째 줄에 정수 N(1 <= N <= 500,000)이 주어진다.
>
> 출력: 1번째 줄에 남는 카드의 번호를 출력한다.

## 2. 나의 접근법

처음에는 큐를 사용해서 그대로 구현해보았다. 매우 간단하게 구현이 가능하지만, 시뮬레이션처럼 구현되다 보니 수가 커지면 커질수록 소요되는 시간도 오래 걸린다는 것을 바로 확인했다. 

```python3
"""
    [2164] 카드 게임
    링크: https://www.acmicpc.net/problem/2164
    카테고리: 자료구조 > 큐
    날짜: 2026.08.23 15:30PM
    걸린 시간: 30분
"""
import sys

N = int(sys.stdin.readline())

queue = [i for i in range(1, N + 1)]

while len(queue) > 1:
    queue.pop(0)
    queue.append(queue.pop(0))

print(*queue)
```

gemini를 통해 물어보니 파이썬의 list는 동적 배열 (Dynamic Array)로, 내가 생각한 Linked List의 형태가 아니다 보니 맨 앞쪽 원소를 삭제할 때마다 뒤에 있는 N-1개의 배열 원소를 앞으로 한 칸씩 당기는 연산이 수행되게 된다. 이 때문에 pop(0)한 번당 원소의 개수만큼 $Θ(n)$이 수행되게 되므로 시간복잡도는 총 $Θ(n^2)$ 이 된다. 즉, N = 500,000일 때 pop(0)를 반복하면, $N^2/2≈1,250억$ 번의 원소 이동 연산이 필요하게 돤다.

그에 비해 deque는 Doubly Linked List로, 메모리의 떨어진 블록을 포인터로 연결한다. 따라서, `popleft()` 연산은 맨 앞을 가리키는 포인터만 한 칸 뒤로 이동시키게 되고 N의 개수와 상관없이 항상 $Θ(1)$ 시간에 처리된다. 따라서 아래와 같이 deque를 사용하면 최악의 케이스도 금방 해결된다.
 
```python3
"""
    [2164] 카드 게임
    링크: https://www.acmicpc.net/problem/2164
    카테고리: 자료구조 > 큐
    날짜: 2026.08.23 15:30PM
    걸린 시간: 30분
"""
import sys
from collections import deque

N = int(sys.stdin.readline())
q = deque(range(1, N + 1))

while len(q) > 1:
    q.popleft()
    q.append(q.popleft())

print(q[0])
```
