이번에도 슬라이딩 윈도우를 활용한 문제이다. 문제 자체는 단순하다. N개의 수와 슬라이딩 윈도우 크기 (L)이 주어지고, N개의 숫자가 주어진다. 각 슬라이딩윈도우에서 가장 최솟값을 찾아내면 되는 문제이다.

두 가지 유의점이 있는데, 한 가지는 슬라이딩 윈도우보다 작은 범위에 있는 값들은 무시해야 하고, 주어진 값들의 범위가 상당히 크다는 점이다.

따라서 그냥 리스트에서 슬라이딩 윈도우로 구현하게 된다면 $Θ(n)$ 으로 구현이 불가능하고, 최악의 경우 $Θ(n \times L)$ ($2.5 \times 10^{13}$) 따라서 제한 시간을 초과하게 된다.

따라서 이 문제 풀이에서는 덱(Deque)을 활용한 단조 큐(Monotonic Queue) 기법 사용을 권장하고 있다.

#### 1\. Deque 활용 기법

Deque이랑 데이터의 앞과 뒤쪽 양쪽 끝에서 모두 삽입과 삭제가 가능한 큐를 의미한다. 이 문제에서는 Deque의 각 노드에 값과 인덱스를 같이 저장한다. 이렇게 저장하는 이유는 데이터를 저장하기 전에 범위에서 벗어난 값들은 제거하면서 정렬의 효과를 계속해서 가져가기 위함이다.

Deque의 원소는 L보다 커질 수 없고 이를 통해 $Θ(n)$ 의 복잡도로 구현이 가능하다.


#### 2\. 수도 코드

> 1\. 입력 값 초기화
> 2\. deque 뒤쪽에서 현재 값보다 큰 값은 삭제
> 3\. deque 마지막 위치에 현재 값 저장
> 4\. deque 첫 번째 위치에서 L의 범위를 벗어난 값 (index <= now index - L)을 덱에서 제거
> 5\. deque의 첫 번째 데이터 출력

이를 구현하면 다음과 같다.

```
"""
    [11003] 최솟값 찾기
    링크: https://www.acmicpc.net/problem/11003
    카테고리: 자료구조 > 슬라이딩 윈도우
    날짜: 2026.08.02 16:00PM
    걸린 시간: 20분
"""
import sys
from collections import deque

N, L = map(int, sys.stdin.readline().split())
A = list(map(int, sys.stdin.readline().split()))

dq = deque()  # (값, 인덱스) 저장
result = []

for i in range(N):
    val = A[i]
    
    # 1. 덱 뒤에서 현재 값보다 크거나 같은 원소 제거 (단조 오름차순 유지)
    while dq and dq[-1][0] >= val:
        dq.pop()
        
    dq.append((val, i))
    
    # 2. 윈도우 범위를 벗어난 원소 제거 (i - L + 1 보다 작은 인덱스)
    if dq[0][1] <= i - L:
        dq.popleft()
        
    # 3. 덱의 맨 앞 원소가 현재 윈도우 최솟값
    result.append(str(dq[0][0]))
    
print(' '.join(result))
```

#### 3\. 회고

시간 복잡도가 얼마나 차이가 날까 해서 책을 통해 Deque을 사용하기 전에 각 케이스마다 L만큼 비교하는 코드로 작성도 해보았는데, 데이터가 매우 큰 케이스에서 시간이 초과하여 통과하지 못하는 것을 확인할 수 있었다.
