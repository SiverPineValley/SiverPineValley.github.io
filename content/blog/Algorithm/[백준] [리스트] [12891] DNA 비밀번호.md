이번에는 슬라이딩 윈도우를 활용한 문제이다. 슬라이딩 윈도우란 투 포인터 알고리즘과 유사하게, 2개의 포인터로 범위를 지정한 다음, 범위를 유지한 채로 이동하며 문제를 해결하는 방식이다. DNA 비밀번호 문제는 ACGT 네 가지 DNA 염기 서열을 사용한 비밀번호가 조건에 맞는 개수를 구하는 문제이다.

투 포인터처럼 초기 두 개의 포인터 범위만큼의 서브 스트링이 결과에 맞는지 확인 후, 포인터를 하나씩 옮겨가며 조건에 맞는지 확인하면 된다. 투 포인터와 한 가지 다른 점은 포인터가 옮겨갈 때마다 추가되는 인덱스를 더하면서, 기존의 첫 번째 인덱스를 제거해야 한다는 점이다.

#### 1\. 수도 코드

> 1\. 입력 값 초기화
> 2\. 추가 / 삭제 함수 초기화
> 3\. 초기 서브 스트링 초기화
> 4\. 각 스트링 옮겨가면서 조건 확인

이를 구현하면 다음과 같다.

```
"""
    [12891] DNA 비밀번호
    링크: https://www.acmicpc.net/problem/12891
    카테고리: 자료구조 > 슬라이딩 윈도우
    날짜: 2026.05.02 16:10PM
    걸린 시간: 20분
"""
import sys

# 초기화
TOTAL_LEN, SUB_STR_LEN = map(int, sys.stdin.readline().split())
dna = sys.stdin.readline()
cons_dna_count = list(map(int, sys.stdin.readline().split()))
sub_dna_count = [0] * 4
check_dna = 0
result = 0

def str_add(c):
    global cons_dna_count, sub_dna_count, check_dna
    if c == 'A':
        sub_dna_count[0] += 1
        if sub_dna_count[0] == cons_dna_count[0]:
            check_dna += 1
    if c == 'C':
        sub_dna_count[1] += 1
        if sub_dna_count[1] == cons_dna_count[1]:
            check_dna += 1
    if c == 'G':
        sub_dna_count[2] += 1
        if sub_dna_count[2] == cons_dna_count[2]:
            check_dna += 1
    if c == 'T':
        sub_dna_count[3] += 1
        if sub_dna_count[3] == cons_dna_count[3]:
            check_dna += 1

def str_del(c):
    global cons_dna_count, sub_dna_count, check_dna
    if c == 'A':
        if sub_dna_count[0] == cons_dna_count[0]:
            check_dna -= 1
        sub_dna_count[0] -= 1
    if c == 'C':
        if sub_dna_count[1] == cons_dna_count[1]:
            check_dna -= 1
        sub_dna_count[1] -= 1
    if c == 'G':
        if sub_dna_count[2] == cons_dna_count[2]:
            check_dna -= 1
        sub_dna_count[2] -= 1
    if c == 'T':
        if sub_dna_count[3] == cons_dna_count[3]:
            check_dna -= 1
        sub_dna_count[3] -= 1

# 초기 서브 스트링 카운트
for i in range(4):
    if cons_dna_count[i] == 0:
        check_dna += 1

for i in range(SUB_STR_LEN):
    str_add(dna[i])

for i in range(SUB_STR_LEN, TOTAL_LEN):
    j = i - SUB_STR_LEN
    str_add(dna[i])
    str_del(dna[j])
    if check_dna == 4:
        result += 1

print(result)
```
