## 1. 문제 소개

> 1부터 n까지의 수를 스택에 저장하고 출력하는 방식으로 하나의 수열을 만들 수 있다. 이 때, 스택에 push하는 순서는 반드시 오름차순을 지키도록 한다고 가정한다.
> 
> 수열이 주여졌을 때 이러한 방식으로 스택을 이용해 주어진 수열을 만들 수 있는지 확인하고 만들 수 있다면 어떤 순서로 push와 pop을 수행해야 하는지 확인하는 프로그램을 작성하시오.
>
> 입력: 1번째 줄에 수열의 개수 n(1 <= n <= 100,000)이 주어진다. 2번째 줄부터 n개의 줄에 수열을 이루는 n이하의 자연수가 1개씩 순서대로 주어진다. 이 때 같은 자연수가 두 번 이상 나오지는 않는다.
>
> 출력: 수열을 만들기 위한 연산 순서를 출력한다. push 연산은 +, pop 연산은 -로 출력하고, 불가능할 때는 NO를 출력한다.

## 2. 나의 접근법

처음에 문제를 이해하지 못해 헤맸던 구간이 있다. n이하의 자연수가 순서대로 입력되고, stack에 쌓였다가 출력되는 시점에 수열이 만들어지는 것인데 이 원리를 이해하지 못해 헤맸던 것 같다.

결론적으로 stack에 수가 append될 때는 +, pop될 때는 -가 출력되어야 하고, 수열을 만들 수 없을 때 NO가 출력되어야 한다. 따라서 연산 순서는 리스트에 가지고 있다가 마지막에 한번에 출력되어야 한다.

스택의 개념 자체가 어렵지는 않지만, 알고리즘을 구현하는 것이 헷갈렸었다.

1. 현재 수열 값 >= 자연수 -> 반복
    1.1. 스택에 추가
    1.2. stack의 top이 현재 수열과 같을 때 pop
2. stack에 남은 길이만큼 출력되어야 하는 수열과 비교해서 같으면 pop, 아니면 NO 출력 후 종료.
3. 결과 출력

```python3
"""
    [1874] 스택으로 수열 만들기
    링크: https://www.acmicpc.net/problem/11003
    카테고리: 자료구조 > 스택
    날짜: 2026.08.04 22:30PM
    걸린 시간: 90분
"""
import sys

n = int(sys.stdin.readline())
nums = [0]

for i in range(n):
    each = int(sys.stdin.readline())
    nums.append(each)

stack = []
result = []

# 자연수와 수열
j = 1
k = 1

while j <= n:
    # 자연수가 현재 수열보다 작거나 같을 때 Push
    if j <= nums[k]:
        stack.append(j)
        result.append("+")
        j += 1

    # stack의 top이 현재 수열과 같을 때 Pop
    if stack[-1] == nums[k]:
        stack.pop()
        result.append("-")
        k += 1

for i in range(len(stack)):
    if stack[-1] == nums[k]:
        stack.pop()
        result.append("-")
        k += 1
    else:
        print("NO")
        exit(0)

for r in result:
    print(r)

```

이와 같이 구현한 이유는 append하는 시점에 대해서는 감을 잡았지만, pop하는 시점이 append 하는 시점과 동시에 이루어질 수 있다고 생각했기 때문이다.
하지만, 수는 증가하지만 stack에 남은 수가 존재할 수 있고 이러한 수들을 반복문 이후에 다시 하나식 비교하는 방식이면 커버가 될 것 이라고 생각했다.
예시 테스트 케이스들은 통과하였지만 다음 케이스들에서 반례가 존재한다.

## 3. 반례

### ❌ 반례 1: 무한 루프 (시간 초과) 발생 케이스                                                
4                                                       
3                                                       
1                                                       
2                                                                                                                           4                                                       

• 코드 진행 과정:
1. 3을 맞추기 위해 j = 1, 2, 3을 push하고 3을 pop합니다. (stack에는 [1, 2]가 남아있음)
2. 다음 목표 값은 nums[k] = 1이고, 현재 j = 4입니다.        
3. while j <= n: 루프 안에서:
    • if j <= nums[k] (4 <= 1) ➡️ 거짓
    • if stack[-1] == nums[k] (2 == 1) ➡️ 거짓
4. 두 조건문 모두 실행되지 않아 j와 k 값이 더 이상 변경되지 않은 채 while문이 무한 루프에 빠지게 됩니다.
                                                         
### ❌ 반례 2: Empty Stack 접근  (IndexError가능성)                      
• stack이 비어 있는 상태에서 j <= nums[k] 조건문이 실행되지 않을 때 stack[-1]에 접근하면 IndexError: list index out of range 예외가 발생할 수 있습니다.

## 4. 올바른 접근법
스택으로 수열을 만들 때는 수열의 **각 요소(target)**에 대해 다음 2단계로 단순화하여 작성하는 것이 훨씬 안전하고 직관적입니다.

1. Push: 현재 넣을 자연수(current)가 target 숫자 이하인 동안 stack에 push(+) 하고 current를 증가시킵니다.
2. Pop / 검증:
    • stack의 최상단(top) 값이 target 숫자와 **같다면 pop(-)**합니다.
    • 만약 다르다면, 오름차순 push 규칙상 원하는 수열을 만드는 것이 **불가능(NO)**하므로 즉시 종료합니다.

```python3
"""
    [1874] 스택으로 수열 만들기
    링크: https://www.acmicpc.net/problem/1874
    카테고리: 자료구조 > 스택
    날짜: 2026.08.04 22:30PM
    걸린 시간: 90분
"""
def main():
    n = int(input())
    sequence = []
    for i in range(n):
        sequence.append(int(input()))

    stack = []
    result = []
    current = 1
    possible = True

    for num in sequence:
        # 1. target 숫자(num)까지 오름차순으로 push
        while current <= num:
            stack.append(current)
            result.append('+')
            current += 1

        # 2. stack의 top이 target 숫자와 일치하면 pop
        if stack and stack[-1] == num:
            stack.pop()
            result.append('-')
        # top이 target과 다르면 수열을 만들 수 없음
        else:
            possible = False
            break

    if possible:
        print('\n'.join(result))
    else:
        print('NO')

if __name__ == '__main__':
    main()
```
