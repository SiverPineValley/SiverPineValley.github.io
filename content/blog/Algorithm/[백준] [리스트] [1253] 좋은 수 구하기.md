> N개의 수 중에서 어떤 수가 다른 수 두 개의 합으로 나타낼 수 있다면 그 수를 “좋다(GOOD)”고 한다. N개의 수가 주어지면 그 중에서 좋은 수의 개수는 몇 개인지 출력하라. 수의 위치가 다르면 값이 같아도 다른 수이다.
> 
> 첫째 줄에는 수의 개수 N(1 ≤ N ≤ 2,000), 두 번째 줄에는 i번째 수를 나타내는 Ai가 N개 주어진다. (|Ai| ≤ 1,000,000,000, Ai는 정수)
> 좋은 수의 개수를 첫 번째 줄에 출력한다.

좋은 수 구하기는 기존과 다르게 시작, 종료, 대상 값이 모두 변수인 점이 다르다. 또한, 주어지는 수들이 정수이다 보니 음수까지 포함될 수 있다는 점에서 좀 더 난이도가 있는 문제였다.

처음에는 문제를 헷갈려서 이전의 문제들처럼 자연수만 포함일 때를 생각하였다. 따라서 대상 값을 고정시키고 대상 값보다 작은 수들 중에서 양 끝의 값을 시작, 종료 값으로 정해서 더 좁은 범위에서 투 포인터를 사용하고, 대상 값을 하나씩 올려가면서 계산하는 방식을 사용하였는데, 이 경우 자연수만 포함된 경우에는 정확했지만, 채점을 돌리면 계속해서 오답이 나와서 몇 번이고 잉? 하게 되었다...

이래서 문제 풀기 전에 문제를 정확하게 이해하는 것이 정말 중요하다.

앞서 설명한 대로 이 문제는 음수를 포함하기 때문에 단방향으로 생각해서 풀이하면 안된다. 예를 들어, 정렬을 했더라도 -5 = -4 + (-1) 처럼 더 큰 값을 더했을 때 더 작은 값이 나오기 때문이다. 따라서 대상 값보다 작은 수들 중에서 양 끝을 선정하면 풀이가 안되었다. 풀이를 위해서는 첫 번째 값은 첫 번째 index, 두 번째 값은 마지막 index로 초기화하여 하나씩 움직여 가는 방식을 택해야 했다.

</br>

#### 1\. 투 포인터 공식 구하기

앞서 설명한대로 투 포인터 공식은 다음과 같다.

- 매 cur마다 초기화: first = 0, second = N -1
- A[first] + A[second] == A[cur]: count += 1
- A[first] + A[second] < A[cur]: first += 1
- A[first] + A[second] > A[cur]: second -= 1

</br>

여기서 한 가지 주의할 점이 있는데, 단순히 A[first] + A[second] == A[cur] 케이스를 찾았더라도 바로 while 문을 break하면 안된다는 점이다. 포인터를 움직이다가 first 혹은 second 값이 k와 일치하는 경우는 제외해야 하기 때문이다. 따라서, 공식은 다음과 같아야 한다.

- 매 cur마다 초기화: first = 0, second = N -1
- A[first] + A[second] == A[cur]:
    - first != cur && second != cur:
        count += 1
        break
    - first == cur:
        first += 1
    - second == cur:
        second -= 1
- A[first] + A[second] < A[cur]: first += 1
- A[first] + A[second] > A[cur]: second -= 1

이를 구현하면 다음과 같다.

```python
"""
    [1253] 좋은 수 구하기
    링크: https://www.acmicpc.net/problem/1253
    카테고리: 자료구조 > 투 포인터
    날짜: 2026.04.23 14:40
    걸린 시간: 60분
"""
import sys

input = sys.stdin.readline

N = int(input())
A = list(map(int, input().split()))

if N < 3:
    print(0)
    sys.exit(0)
A.sort()
count = 0

for cur in range(N):
    first = 0
    second = N - 1
    while first < second:
        s = A[first] + A[second]
        if s == A[cur]:
            if first != cur and second != cur:
                count += 1
                break
            elif first == cur:
                first += 1
            elif second ==cur:
                second -= 1
        elif s < A[cur]:
            first += 1
        else:
            second -= 1

print(count)
```
